# Supervised Machine Learning: Regression and Classification
___

### 1- Supervised learning : The algorithm learns from `labeled` data, each input comes with a correct output. The goal is prediction or classification based on the data and our goal 
> `Example` : Predicting house prices , train a model with dataset of houses (input) and thier prices(output), the model learns the relationship so it can perdict for new input (houses)

#### Algorithms:
- Linear regression

- Logistic regression

- Decision trees

- Support vector machines (SVM)

---
### 2- Unsupervised Learning : The algorithm learns from `unlabeled` data, only the inputs are given without known output. The goal is to find hidden patterns or strcture in the data 
> `Examples` : Sentiment Analysis (for marketing purposes): classifying online reviews or social media posts into positive or negative
### Algorithms: 
- K-means clustering

- Hierarchical clustering

- Principal Component Analysis (PCA)

- Autoencoders
